# CanvaCraft UI 확정 기준

확정일: 2026-11-06. 사용자 요구: 어린이가 Canva에서 익힌 위치와 조작 흐름을 그대로 사용할 수 있게 한다. 차트는 제외하고 도형·캐릭터를 풍부하게 제공한다. **Phase 4부터 이 문서를 기준으로 구현하며 추가 UI 확정을 기다리지 않는다.**

참고: https://www.canva.com/ko_kr/presentations/ 상단 25초 한국어 소개 영상. 영상에서 실제 관찰한 배치와 우리 제품의 세부 결정을 아래에서 구분한다. 실제 Canva 계정 편집기를 조작한 것은 아니므로 모든 메뉴가 현재 Canva와 동일하다고 주장하지 않는다.

## 1. 확정한 화면 구조

| 영역 | 확정 기준 |
|---|---|
| 상단 바 | 청록→파랑→보라 그라데이션. 왼쪽부터 작품 목록으로 돌아가기, 파일 메뉴, 실행 취소·다시 실행, 작품 이름·저장 상태. 오른쪽에 발표와 공유 버튼 |
| 왼쪽 도구 모음 | 폭 72px. 아이콘+한글 이름. 위에서 배경 / 요소 / 텍스트 / 업로드 / 그리기 / 템플릿 순서(2026-11-06 사용자 결정: 배경을 자주, 템플릿은 가끔 쓴다) |
| 왼쪽 세부 패널 | 도구 모음 바로 오른쪽, 기본 폭 304px. 검색·카테고리·미리보기. 오른쪽 위 닫기 X. 다른 도구를 누르면 같은 영역의 내용만 바뀜 |
| 중앙 작업 공간 | 밝은 회색 바탕, 가운데 16:9 슬라이드. 패널이 열리면 남은 영역에 슬라이드를 맞춤. 패널이 슬라이드 위를 덮지 않음 |
| 요소 설정 | 선택한 요소의 설정만 작업 영역 상단의 가로 도구 줄에 표시. 설정 변경을 위해 별도 화면으로 이동하지 않음 |
| 하단 슬라이드 목록 | 가로 미리보기·장 번호. 현재 장 보라 테두리. 마지막에 + 페이지 추가. 가로 스크롤·드래그 순서 변경. 왼쪽 세로 목록으로 바꾸지 않음 |
| 오른쪽 아래 | 확대/축소 슬라이더·백분율·화면 맞춤·전체 화면. 슬라이드 목록 및 선택 손잡이와 겹치지 않음 |

72px·304px 등 수치는 우리 앱 구현 기본값이며 영상 실측값은 아니다. 영상에서 확인한 구조는 상단 그라데이션·발표/공유, 왼쪽 좁은 아이콘 열과 펼쳐진 패널, 가운데 작업 공간, 아래 가로 미리보기·+ 타일, 보라색 선택 표시, 오른쪽 아래 확대/축소다. 상단 파일 메뉴, 도구 명칭·순서, 선택별 설정 줄, 다운로드 경로는 이 제품에서 확정한 규칙이다.

화면에서 브랜드명은 CanvaCraft를 사용한다. 기존 Phase 2의 큰 소개 문구, 카드형 도구 모음, 시험용 출력 버튼 나열은 정식 편집기에 사용하지 않는다. 아이들이 익숙한 편집기 구조를 유지하고, 독립적인 어린이용 대시보드로 재설계하지 않는다.

## 2. 도구별 패널

| 도구 | 펼쳐지는 내용 | 슬라이드에 넣는 방법 |
|---|---|---|
| 템플릿 | 시작 템플릿 카드. 복잡한 템플릿 편집 기능은 추가하지 않음. 제공 배경은 배경 패널에만 둔다 | 카드를 누르면 지금 작품을 저장하고 새 작품으로 연다 |
| 요소 | 통합 검색. 전체 / 도형 / 캐릭터 / 스티커 탭. 최근 사용 항목, 카테고리별 카드 | 카드 클릭으로 현재 장 중앙에 추가하고 바로 선택. 기존 내용은 유지 |
| 텍스트 | 제목 추가 / 부제목 추가 / 본문 추가, 글씨 스타일 예시 | 텍스트 상자 추가 후 입력 상태로 전환 |
| 업로드 | 파일 업로드 버튼, 넣은 사진 목록 | 사진 클릭으로 추가. 드롭·이미지 붙여넣기도 지원. 새 사진은 기존 요소 위에 추가 |
| 그리기 | 펜, 색상 팔레트, 굵기, 획 지우개, 선택으로 돌아가기 | 그리기 모드에서만 획 입력. 지우개는 획만 삭제 |
| 배경 | 단색 팔레트, 제공 배경 카테고리·미리보기, 사진 배경 선택 | 현재 장의 배경만 변경하고 사진·글씨·그림은 보존 |

사진 붙여넣기를 위해 UI를 다른 곳으로 이동하지 않는다. 텍스트 입력 중 Ctrl+V는 일반 글씨 붙여넣기다. 요소 Ctrl+C/V 복사는 기존 결정대로 후속 범위이며 복제 버튼을 사용한다.

## 3. 도형·캐릭터·스티커 범위

차트·표·데이터 입력, 실시간 협업, 녹화, AI 생성, 유료 기능 안내는 첫 버전 도구 목록과 검색 결과에 넣지 않는다. 영상의 차트 패널은 펼침 방식·선택 테두리의 참고다. 차트 자체를 구현하라는 뜻이 아니다.

첫 버전 출시용 자산 목표는 **최소 120개**다. 이는 아직 보유·검증한 수량이 아니라 구현 완료 기준이다.

- 도형 24개 이상: 원·타원·정사각형·직사각형·둥근 사각형·삼각형·마름모·다각형·별·하트·방향 화살표·말풍선 등. 동일 도형의 색만 바꾼 것은 별개 종류 수에 포함하지 않는다.
- 캐릭터 60개 이상: 어린이 인물, 동물, 공룡·상상 친구 등을 나누고 표정·동작이 보이는 자산을 제공한다. 동일 그림의 색 변경은 수량을 채우는 데 쓰지 않는다.
- 꾸미기 스티커 36개 이상: 학교·문구, 자연·날씨, 음식, 탈것·놀이, 축하·감정 등.

요소 패널의 그림과 업로드 패널의 넣은 사진은 누르면 슬라이드 가운데에, 끌어다 놓으면 놓은 곳에 들어간다. 요소 패널에 한국어 이름·검색 태그를 붙인다. 검색 예: 고양이, 웃음, 친구, 하트, 화살표. 카테고리 칩과 검색을 함께 제공하고 한 화면에는 약 3열 카드로 표시한다. 캐릭터·스티커는 투명 배경을 기본으로 하며 자산은 같은 origin에서 제공한다. 외부 검색이나 네트워크 다운로드를 편집 과정에 요구하지 않는다.

도형은 삽입 전에 패널에서 색을 선택할 수 있게 한다. 첫 버전의 도형·캐릭터·스티커는 투명 PNG 이미지 요소로 삽입해 기존 addImage·선택·크기 조절·복제·저장·출력 경로를 사용한다. 도형은 대표 종횡비별 카드를 제공하고 삽입 후 비율 유지 크기 조절을 적용한다. 자유 변형·꼭짓점 편집·삽입 후 도형 채우기색 편집은 첫 버전 필수 기능이 아니다. 이를 추가하려면 문서 타입과 명령·출력 계약을 먼저 변경한다.

캐릭터는 원본 자산을 직접 제작하거나 재배포·출력 권한을 확인한 것만 사용하고 docs/asset-licenses.md에 출처·사용 조건을 기록한다. Canva 로고·인물 사진·유료 캐릭터를 가져오지 않는다. UI 구조 참고와 콘텐츠 사용은 구분한다. 자산을 골라 모으는 일은 아직 수행하지 않았다.

## 4. 선택·이동·편집 동작

- 한 번 클릭하면 보라 테두리와 흰색 손잡이로 선택. 빈 작업 영역 클릭 또는 Escape로 해제. 선택 상태는 저장 데이터가 아니다.
- 끌어서 이동. 사진·도형·캐릭터·스티커는 모서리로 비율 유지 크기 조절. 텍스트는 좌우로 폭 조절, 모서리로 폭·글씨 크기 비례 조절. 획은 이동만 허용.
- 텍스트 더블클릭/더블탭으로 입력. 사진을 더블클릭했다고 미구현 자르기 화면을 열지 않는다.
- 사진·그림 자산 선택 줄: 복제, 앞뒤 순서, 삭제. 텍스트 선택 줄: 글꼴, 크기, 굵게, 색, 정렬과 공통 동작. 도형도 첫 버전에서는 이미지 규칙을 사용한다.
- 우클릭 또는 선택 근처 더보기 메뉴: 복제 / 앞으로 / 뒤로 / 삭제. 터치에서는 더보기 버튼으로 같은 명령에 접근한다.
- Delete는 선택 요소 삭제, Ctrl+Z·Ctrl+Shift+Z는 취소·다시 실행. 입력창 포커스와 IME 조합 중에는 문서 단축키가 끼어들지 않는다.
- 슬라이드 목록의 장 메뉴: 복제 / 삭제 / 내용 비우기 / 왼쪽으로 / 오른쪽으로. 드래그 외의 순서 변경 경로도 유지한다.
- 이미 구현된 명령과 취소 단위를 그대로 사용한다. 문서 변경은 store의 dispatch·undo·redo로만 수행한다.

## 5. 저장·발표·다운로드 위치

상단 파일 메뉴에 새 작품·원본 열기·원본 저장·이 컴퓨터에 저장을 둔다. 저장 상태는 작품 이름 근처에서 표시한다. 여러 작품의 시작 화면과 자동 저장은 Phase 8에서 구현했다. 왼쪽 위 뒤로 버튼이 작품 목록으로 간다. 이 컴퓨터에 저장은 예약을 기다리지 않고 바로 저장한다.

상단 공유 → 다운로드로 내려받기 패널을 연다. 파일 형식은 PowerPoint(.pptx) / PDF / 모양 그대로 PowerPoint로 표시한다. '모양 그대로'는 개별 글씨 수정이 안 된다는 안내를 붙인다. 구현용 auto/explicit/PNG/JPEG 옵션은 제품 화면에 노출하지 않는다. 발표는 상단 별도 버튼이며 전체 화면에서 이전·다음·종료에 접근할 수 있게 한다(Phase 9 구현: 아래쪽 조작 줄, 방향키·스페이스·Esc, 화면 누르기). 내려받기 창은 파일을 만드는 동안 진행률과 취소를, 끝나면 결과와 경고를 보여 준다. 온라인 공유 링크·권한 설정은 첫 버전 범위가 아니다.

## 6. 단계별 적용과 완료 기준

| 단계 | 적용 범위 |
|---|---|
| Phase 4 | 상단·왼쪽 도구·세부 패널·중앙·하단 목록의 배치로 임시 틀 교체. 선택·이동·크기·장 순서. 미구현 도구는 위치를 유지하고 준비 상태 안내 |
| Phase 5 | 사진·배경과 함께 요소 라이브러리 연결. 먼저 도형 24개와 캐릭터/스티커 샘플로 선택·저장·출력 경로 검증. 전체 120개는 Phase 10까지 채움 |
| Phase 6~7 | 텍스트 설정 줄과 그리기 패널 완성 |
| Phase 8~9 | 작품·저장 상태·원본 메뉴, 공유→다운로드, 발표 연결 |
| Phase 10 | 자산 120개·검색·라이선스 및 어린이 사용 흐름 확인(자동 점검 완료, 어린이 사용성 관찰은 미실시) |

PC 1366×768과 1280×720을 기준으로 상단·하단 UI가 잘리지 않고 슬라이드가 남은 영역에 맞아야 한다. 태블릿 가로 화면은 같은 배치를 유지하되 패널을 닫아 공간을 확보한다. 세로 모바일용 독립 UI는 만들지 않는다. UI 버튼 터치 영역은 44px 목표다.

화면 구현 후 브라우저에서 패널 열기/닫기, 요소 선택, 텍스트 입력, 가로 장 목록 상태를 실제 관찰한다. 50%·100%·150% 확대에서도 좌표·손잡이 동작이 맞아야 한다. UI 변경으로 기존 flow.spec.ts의 저장·출력 왕복을 깨뜨리지 않는다.

**결정 완료:** 별도 UI 설계 문서 작성이나 추가 Canva 조사 완료를 Phase 4 착수 조건으로 걸지 않는다. 부족한 세부는 이 제품 결정에 따라 구현하며 실제 Canva와 일치한다고 검증한 범위와 구분해 보고한다. 이 문서는 설계 확정이며 앱 UI 반영·자산 수집 완료를 뜻하지 않는다.
