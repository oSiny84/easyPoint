# CanvaCraft 사용 설명

어린이와 보호자·선생님을 위한 안내다. Windows 10·11 PC의 Chrome 또는 Edge에서 쓴다.

## 집 컴퓨터에 준비하기(보호자)

1. `CanvaCraft.exe` 파일 하나를 USB 등으로 옮겨 바탕화면에 둔다. 설치도 인터넷도 필요 없다.
2. 두 번 누르면 브라우저에 CanvaCraft가 열린다. Windows가 파란 경고 창을 띄우면 `추가 정보` → `실행`을 누른다. 서명하지 않은 파일이라 인터넷으로 받았을 때 나올 수 있다.
3. 기본 브라우저가 Chrome이나 Edge인지 확인한다.

브라우저를 닫아도 프로그램은 오른쪽 아래 알림 영역에 남아 있다. 컴퓨터를 느리게 하지 않으며, `CanvaCraft.exe`를 다시 누르면 다시 열린다. 완전히 끝내려면 알림 영역의 CanvaCraft 아이콘을 오른쪽 단추로 눌러 `끝내기`를 고른다.

작품은 그 컴퓨터의 그 브라우저에 저장된다. 다른 컴퓨터나 개발용 주소에서 만든 작품은 보이지 않으므로 `원본 저장`으로 내려받아 `원본 열기`로 옮긴다. `CanvaCraft.exe`를 지우거나 새 버전으로 바꿔도 작품은 지워지지 않는다.

## 시작하기

- 처음 들어오면 시작 화면이 나온다. `슬라이드 만들기`를 누르면 `내 작품` 목록이 나오고, `새 작품`을 누르면 빈 작품이 열린다. 아래 `최근 작품`을 누르면 그 작품으로 바로 들어간다.
- 목록에서 작품을 누르면 이어서 고칠 수 있고, `템플릿으로 시작`을 누르면 틀이 있는 새 작품이 열린다.
- 왼쪽 위 `<` 단추를 누르면 작품 목록으로, 작품 목록 왼쪽 위 집 모양 단추를 누르면 시작 화면으로 돌아간다.
- `영상 만들기`: 영상 도구의 `영상 가져오기`나 화면에 끌어다 놓기로 MP4·MOV·WebM을 넣고, 자르고, 자막·밈·음악을 얹어 `내보내기`로 MP4 파일을 만든다. 배경음악 4곡·효과음 12개가 들어 있고, 밈은 가족 그림이 들어오기 전까지 연습용이다.
- 자막: 자막 도구에서 `보통 자막 추가` 등을 누르고 글자를 쓴다. 두 번 누르면 고치고, 끌면 옮기고, 모서리로 크기를 바꾼다. 위 설정 줄의 `−`/`+`로 보이는 시간을 1초씩, `지금부터`로 시작을 재생 막대 위치로 바꾼다.
- 밈·소리: 밈 도구에서 카드를 누르거나 화면에 끌어다 놓는다. 같은 때 보이는 밈 영상은 2개, 스티커는 4개까지다. 소리 도구에서 영상 원래 소리 크기와 배경음악을 고른다.
- 내보내기: 상단 `내보내기`를 누르면 다 만든 뒤 파일을 내려받는다. YouTube에는 보호자 계정으로 올린다.
- 영상 편집: 아래 타임라인의 눈금을 누르거나 빨간 재생 막대를 끌어 위치를 옮긴다. 조각을 누르면 위에 `여기서 자르기`·앞뒤 옮기기·소리 끄기·지우기가 나오고, 선택한 조각의 양 끝 보라색 손잡이를 끌면 앞뒤를 다듬는다. 스페이스로 재생·일시정지한다.

## 꾸미기

| 하고 싶은 일 | 방법 |
|---|---|
| 그림 넣기 | 왼쪽 `요소`에서 그림을 누르거나 슬라이드로 끌어다 놓는다. 터치 화면에서는 누른다 |
| 사진 넣기 | 왼쪽 `업로드`의 `파일 업로드`를 누르거나, 사진 파일을 끌어다 놓거나, 복사한 그림을 Ctrl+V로 붙여 넣는다 |
| 글씨 넣기 | 왼쪽 `텍스트`에서 제목이나 본문을 고르고 입력한다. 글씨를 두 번 누르면 다시 고칠 수 있다 |
| 글꼴·크기·색 바꾸기 | 글씨를 한 번 눌러 고른 뒤 위쪽 설정 줄을 쓴다 |
| 그리기 | 왼쪽 `그리기`에서 펜으로 그린다. `획 지우개`로 문지르면 그 획이 지워진다 |
| 배경 바꾸기 | 왼쪽 맨 위 `배경`에서 색이나 그림, 사진을 고른다. 지금 장만 바뀐다 |
| 템플릿으로 시작 | 왼쪽 맨 아래 `템플릿`이나 작품 목록에서 고른다. 지금 작품은 저장되고 새 작품으로 열린다 |
| 옮기기·크기 바꾸기 | 눌러서 끌면 옮겨지고, 모서리 동그라미를 끌면 크기가 바뀐다 |
| 잘못했을 때 | 위쪽 되돌리기 단추나 Ctrl+Z를 쓴다 |
| 장 늘리기·순서 바꾸기 | 아래 `+`로 늘린다. 장을 끌어서 옮기거나 장의 `…` 메뉴를 쓴다 |

## 저장

- 고치면 잠시 뒤 저절로 저장된다. 작품 이름 옆에 `저장됨`이 보이면 끝난 것이다.
- `저장 실패`가 보이면 `파일` 메뉴의 `원본 저장`으로 작품을 내려받아 둔다.
- 작품은 **이 컴퓨터의 이 브라우저에만** 저장된다. 다른 컴퓨터에는 나타나지 않는다. 브라우저의 사이트 데이터를 지우면 함께 사라진다.
- 소중한 작품은 `원본 저장`으로 파일(`.canvacraft`)을 내려받아 둔다. 다른 컴퓨터에서는 `원본 열기`로 연다.

## 발표

위쪽 `발표`를 누르면 지금 장부터 전체 화면으로 보여 준다.

| 하고 싶은 일 | 방법 |
|---|---|
| 다음 장 | 방향키, 스페이스, 화면 누르기 |
| 앞 장 | 왼쪽 방향키, 화면 왼쪽 부분 누르기 |
| 끝내기 | Esc, 아래쪽 `끝내기` |

## 파일로 내려받기

위쪽 `공유` → `다운로드`에서 고른다.

| 형식 | 이럴 때 | 알아 둘 점 |
|---|---|---|
| PowerPoint (.pptx) | PowerPoint에서 글씨와 사진을 고치고 싶을 때 | 글꼴이 맑은 고딕으로 바뀌고 줄이 화면과 다르게 나뉠 수 있다 |
| 모양 그대로 PowerPoint | 화면과 똑같이 보여 주고 싶을 때 | 글씨를 하나씩 고칠 수 없다 |
| PDF | 어디서나 같은 모양으로 보고 인쇄할 때 | 고칠 수 없다 |

파일을 만드는 동안 `취소`를 누를 수 있고, 취소한 뒤 다시 받을 수 있다.

## 공용 컴퓨터에서 쓸 때

1. 다 만들면 `원본 저장`으로 파일을 내려받아 자기 저장 장치에 옮긴다.
2. 작품 목록에서 휴지통 단추를 눌러 작품을 지운다.

## 문제가 생겼을 때

| 보이는 안내 | 할 일 |
|---|---|
| `읽기 전용` | 같은 작품이 다른 탭에 열려 있다. 그 탭에서 고치거나, 그 탭을 닫고 새로고침한다 |
| `저장 실패` | `원본 저장`으로 내려받는다. 저장 공간이 부족하면 안 쓰는 작품을 지운다 |
| `글꼴을 불러오지 못했어요` | 인터넷 연결을 확인하고 새로고침한다 |
| `문제가 생겼어요` | `새로고침`을 누른다. 마지막으로 저장된 작품은 그대로 있다 |
| 사진이 안 들어가요 | PNG·JPEG·WebP만 넣을 수 있다. 움직이는 그림과 iPhone 사진 형식(HEIC)은 넣을 수 없다 |
