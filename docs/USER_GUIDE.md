# easyCraft 사용 설명

앱 이름은 2026-11-12에 CanvaCraft에서 easyCraft로 바꿨다. 원본 파일 확장자(`.canvacraft` 등)와 브라우저 저장소 이름은 예전 작품이 그대로 열리도록 바꾸지 않았다. 예전 `CanvaCraft.exe`로 만든 작품도 새 `easyCraft.exe`에서 그대로 보인다(같은 주소를 쓴다).

어린이와 보호자·선생님을 위한 안내다. Windows 10·11 PC의 Chrome 또는 Edge에서 쓴다.

## 집 컴퓨터에 준비하기(보호자)

1. `easyCraft.exe` 파일 하나를 USB 등으로 옮겨 바탕화면에 둔다. 설치도 인터넷도 필요 없다.
2. 두 번 누르면 브라우저에 easyCraft가 열린다. Windows가 파란 경고 창을 띄우면 `추가 정보` → `실행`을 누른다. 서명하지 않은 파일이라 인터넷으로 받았을 때 나올 수 있다.
3. 기본 브라우저가 Chrome이나 Edge인지 확인한다.

브라우저를 닫아도 프로그램은 오른쪽 아래 알림 영역에 남아 있다. 컴퓨터를 느리게 하지 않으며, `easyCraft.exe`를 다시 누르면 다시 열린다. 완전히 끝내려면 알림 영역의 easyCraft 아이콘을 오른쪽 단추로 눌러 `끝내기`를 고른다.

작품은 그 컴퓨터의 그 브라우저에 저장된다. 다른 컴퓨터나 개발용 주소에서 만든 작품은 보이지 않으므로 `원본 저장`으로 내려받아 `원본 열기`로 옮긴다. `easyCraft.exe`를 지우거나 새 버전으로 바꿔도 작품은 지워지지 않는다.

## 시작하기

- 처음 들어오면 시작 화면이 나온다. `슬라이드 만들기`를 누르면 `내 작품` 목록이 나오고, `새 작품`을 누르면 빈 작품이 열린다. 아래 `최근 작품`을 누르면 그 작품으로 바로 들어간다.
- 목록에서 작품을 누르면 이어서 고칠 수 있고, `템플릿으로 시작`을 누르면 틀이 있는 새 작품이 열린다.
- 왼쪽 위 `<` 단추를 누르면 작품 목록으로, 작품 목록 왼쪽 위 집 모양 단추를 누르면 시작 화면으로 돌아간다.
- 시작 화면에서 `영상 만들기`를 누르면 영상 작품 목록이 나온다. 아래 [영상 만들기](#영상-만들기)를 본다.
- 시작 화면에서 `애니메이션 만들기`를 누르면 애니메이션 작품 목록이 나온다. 아래 [애니메이션 만들기](#애니메이션-만들기)를 본다.
- 시작 화면에서 `만화 만들기`를 누르면 만화 작품 목록이 나온다. 아래 [만화 만들기](#만화-만들기)를 본다.

## 꾸미기

| 하고 싶은 일 | 방법 |
|---|---|
| 그림 넣기 | 왼쪽 `요소`에서 그림을 누르거나 슬라이드로 끌어다 놓는다. 터치 화면에서는 누른다 |
| 사진 넣기 | 왼쪽 `업로드`의 `파일 업로드`를 누르거나, 사진 파일을 끌어다 놓거나, 복사한 그림을 Ctrl+V로 붙여 넣는다 |
| 글씨 넣기 | 왼쪽 `텍스트`에서 제목이나 본문을 고르고 입력한다. 글씨를 두 번 누르면 다시 고칠 수 있다 |
| 글꼴·크기·색 바꾸기 | 글씨를 한 번 눌러 고른 뒤 위쪽 설정 줄을 쓴다 |
| 그리기 | 왼쪽 `그리기`에서 펜으로 그린다. `획 지우개`로 문지르면 그 획이 지워진다 |
| 배경 바꾸기 | 왼쪽 맨 위 `배경`에서 색이나 그림, 사진을 고른다. 지금 장만 바뀐다 |
| 템플릿으로 시작 | 왼쪽 맨 아래 `템플릿`이나 작품 목록에서 고른다. 지금 작품은 저장되고 새 작품으로 열린다 |
| 옮기기·크기 바꾸기 | 눌러서 끌면 옮겨지고, 모서리 동그라미를 끌면 크기가 바뀐다 |
| 잘못했을 때 | 위쪽 되돌리기 단추나 Ctrl+Z를 쓴다 |
| 장 늘리기·순서 바꾸기 | 아래 `+`로 늘린다. 장을 끌어서 옮기거나 장의 `…` 메뉴를 쓴다 |

## 저장

- 고치면 잠시 뒤 저절로 저장된다. 작품 이름 옆에 `저장됨`이 보이면 끝난 것이다.
- `저장 실패`가 보이면 `파일` 메뉴의 `원본 저장`으로 작품을 내려받아 둔다.
- 작품은 **이 컴퓨터의 이 브라우저에만** 저장된다. 다른 컴퓨터에는 나타나지 않는다. 브라우저의 사이트 데이터를 지우면 함께 사라진다.
- 소중한 작품은 `원본 저장`으로 파일(`.canvacraft`)을 내려받아 둔다. 다른 컴퓨터에서는 `원본 열기`로 연다.

## 발표

위쪽 `발표`를 누르면 지금 장부터 전체 화면으로 보여 준다.

| 하고 싶은 일 | 방법 |
|---|---|
| 다음 장 | 방향키, 스페이스, 화면 누르기 |
| 앞 장 | 왼쪽 방향키, 화면 왼쪽 부분 누르기 |
| 끝내기 | Esc, 아래쪽 `끝내기` |

## 파일로 내려받기

위쪽 `공유` → `다운로드`에서 고른다.

| 형식 | 이럴 때 | 알아 둘 점 |
|---|---|---|
| PowerPoint (.pptx) | PowerPoint에서 글씨와 사진을 고치고 싶을 때 | 글꼴이 맑은 고딕으로 바뀌고 줄이 화면과 다르게 나뉠 수 있다 |
| 모양 그대로 PowerPoint | 화면과 똑같이 보여 주고 싶을 때 | 글씨를 하나씩 고칠 수 없다 |
| PDF | 어디서나 같은 모양으로 보고 인쇄할 때 | 고칠 수 없다 |

파일을 만드는 동안 `취소`를 누를 수 있고, 취소한 뒤 다시 받을 수 있다.

## 영상 만들기

휴대폰으로 찍은 영상을 이어 붙이고 자막·밈·음악을 얹어 MP4 파일로 만든다. 작품 하나는 기본 10분까지이고, 보호자가 영상 작품 목록 위쪽 `길이 한도`에서 분·시간 단위나 무제한으로 바꿀 수 있다. 한도는 이 브라우저에만 적용되고, 한도를 줄여도 이미 만든 작품은 열린다. 길게 정하면 영상 파일 크기 한도도 함께 늘어나지만(10분마다 2GB) 내보내기가 그만큼 오래 걸린다.

| 하고 싶은 일 | 방법 |
|---|---|
| 영상 넣기 | 왼쪽 `영상` 도구의 `영상 가져오기`를 누르거나 화면에 끌어다 놓는다. MP4·MOV·WebM. 한 파일의 길이·크기는 길이 한도를 따른다(기본 10분·2GB) |
| 위치 옮기기·재생 | 아래 타임라인의 눈금을 누르거나 빨간 재생 막대를 끈다. 스페이스로 재생·일시정지한다(조각이나 단추를 마우스로 누른 뒤에도 된다. 글자를 넣는 칸에서는 빈칸이 들어간다) |
| 타임라인 크게·작게 보기 | 타임라인 오른쪽 막대를 오른쪽으로 밀면 크게(1초 눈금까지), 왼쪽 끝으로 밀거나 옆의 맞춤 단추(네모 모양)를 누르면 작품 전체가 한 화면에 보인다. 몇 시간짜리 작품도 한 화면에 들어오고 눈금이 분·시간 간격으로 바뀐다 |
| 자르기·다듬기 | 조각을 누르면 위에 `여기서 자르기`·앞뒤 옮기기·소리 끄기·지우기가 나온다. 선택한 조각 양 끝의 보라색 손잡이를 끌면 앞뒤를 다듬는다 |
| 빠르게·느리게 | 원하는 부분의 앞뒤를 `여기서 자르기`로 떼어 낸 뒤, 그 조각을 누르고 위 설정 줄의 빠르기(느리게 0.5배·보통·1.5배·2배·4배)를 고른다. 조각의 소리도 함께 빨라져 목소리가 높아진다(느리게 하면 낮아진다). 타임라인 조각에 `2배`처럼 표시된다 |
| 자막 | `자막` 도구에서 `보통 자막 추가` 등을 누르고 글자를 쓴다. 두 번 누르면 고치고, 끌면 옮기고, 모서리로 크기를 바꾼다. 위 설정 줄의 `−`/`+`로 보이는 시간을 1초씩, `지금부터`로 시작을 재생 막대 위치로 바꾼다 |
| 밈 | `밈` 도구에서 카드를 누르거나 화면에 끌어다 놓는다. 같은 때 보이는 밈 영상은 2개, 움직이는 스티커는 4개까지다. 밈은 가족 그림이 들어오기 전까지 연습용이다 |
| 소리·음악 | `소리` 도구에서 영상 원래 소리 크기와 배경음악(4곡)을 고른다. `들어 보기`로 미리 듣는다. 효과음 12개는 밈에 붙어 있다 |
| 파일로 만들기 | 위쪽 `내보내기`를 누르면 다 만든 뒤 MP4 파일을 내려받는다. 개발 PC에서 10분 작품이 약 1분 30초 걸렸고, 느린 PC에서는 더 걸린다. 만드는 동안 이 탭은 닫지 않는다 |
| YouTube에 올리기 | **보호자 계정으로** YouTube 스튜디오의 `만들기` → `동영상 업로드`에서 내려받은 파일을 고른다. 처음에는 비공개로 올려 확인한다 |
| 다른 컴퓨터로 옮기기 | `파일` → `원본 저장`으로 `.canvavideo` 파일을 내려받는다. 넣은 영상이 함께 들어가 크다(지금은 1GB까지) |

넣은 영상은 브라우저 저장 공간에 복사된다. 원래 파일을 지워도 작품은 남지만 디스크를 그만큼 쓴다. 다 만든 작품은 목록에서 지우면 공간이 돌아온다.

## 애니메이션 만들기

그림을 한 장씩 조금씩 바꿔 그리면 움직이는 영상이 된다(종이를 넘겨 보는 그림책과 같다). 그리는 방법은 슬라이드와 똑같고, 장을 넘기는 빠르기·음악·재생·영상 내려받기가 더 있다.

| 하고 싶은 일 | 방법 |
|---|---|
| 첫 장 그리기 | 배경·요소·텍스트·업로드·그리기 도구를 슬라이드와 같은 방법으로 쓴다 |
| 다음 장 만들기 | 아래 장 목록 끝의 `+`를 누른다. 지금 장이 그대로 복사된 새 장이 생긴다. 그림을 조금 옮기거나 고쳐 그린다 |
| 앞 장 겹쳐 보기 | 앞 장이 흐리게 깔려 보여 얼마나 움직였는지 알 수 있다. 오른쪽 아래 겹친 종이 모양 단추나 `애니메이션` 도구에서 켜고 끈다. 영상에는 나오지 않는다 |
| 빈 장 넣기 | 장 위의 `⋯` 메뉴에서 `빈 장 추가`를 고른다. 그 장 바로 뒤에 흰 장이 생긴다 |
| 빠르기 바꾸기 | `애니메이션` 도구에서 1초에 넘기는 장 수(2·4·6·8·12장)를 고른다. 아래에 전체 장 수와 길이가 보인다 |
| 한 장을 오래 보여 주기 | 장 위의 `⋯` 메뉴에서 `길게 보이기`를 `길게 (2배)`나 `아주 길게 (4배)`로 고른다. 장 그림에 `×2`·`×4`가 붙는다 |
| 음악 넣기 | `애니메이션` 도구에서 배경음악(4곡)과 크기를 고른다. `들어 보기`로 미리 듣는다 |
| 움직임 보기 | 위쪽 `재생`을 누른다. 지금 장부터 끝까지 간 뒤 처음부터 반복한다. `멈추기`·Esc·바깥을 누르면 멈춘 장으로 돌아온다 |
| 영상으로 내려받기 | 위쪽 `공유` → `다운로드`에서 `영상 (MP4)`를 고르고 `내려받기`를 누른다. 사진이 많은 100장 작품이 개발 PC에서 약 12초 걸렸고, 느린 PC에서는 더 걸린다 |
| 종이에 뽑기 | 같은 창에서 PDF를 고르면 장마다 한 쪽으로 나온다 |
| YouTube에 올리기 | **보호자 계정으로** YouTube 스튜디오의 `만들기` → `동영상 업로드`에서 내려받은 파일을 고른다 |
| 장난감·점토로 만들기 | 휴대폰으로 한 장씩 찍은 사진을 `업로드`로 장마다 넣는다. 카메라로 바로 찍는 기능은 아직 없다 |
| 다른 컴퓨터로 옮기기 | `파일` → `원본 저장`으로 `.canvaanim` 파일을 내려받는다 |

장은 100장까지 만들 수 있다. 애니메이션 작품은 슬라이드 작품과 따로 보관되며 파일도 서로 다르다. 슬라이드 원본(`.canvacraft`)은 애니메이션에서, 애니메이션 원본(`.canvaanim`)은 슬라이드에서 열리지 않는다.

## 만화 만들기

칸을 하나씩 그리고 말풍선으로 대사를 넣으면, 칸들이 종이 한 쪽에 모인 만화가 된다. 그리는 방법은 슬라이드와 똑같고, 말풍선·효과 그림·칸 배치·만화 보기·만화책 내려받기가 더 있다.

| 하고 싶은 일 | 방법 |
|---|---|
| 첫 칸 그리기 | 배경·요소·텍스트·업로드·그리기 도구를 슬라이드와 같은 방법으로 쓴다. 화면에 보이는 한 장이 칸 하나다 |
| 말풍선 넣기 | `만화` 도구에서 말풍선 모양을 누른다. 칸 가운데에 말풍선이 생기고 바로 대사를 칠 수 있다. 다 쓰면 바깥을 누르거나 Esc를 누른다 |
| 말풍선 옮기기 | 말풍선이나 그 안의 글씨를 끌면 둘이 함께 움직인다. 말풍선을 지우면 글씨도 지워지고, 복제하면 글씨도 복제된다 |
| 대사가 길 때 | 말풍선을 누른 뒤 모서리 손잡이로 키운다. 글씨 자리도 함께 맞춰진다. 글씨 크기는 글씨를 누르면 나오는 위쪽 줄에서 바꾼다 |
| 대사 고치기 | 글씨를 두 번 누른다 |
| 꼬리 방향 바꾸기 | 말풍선마다 왼쪽 꼬리와 오른쪽 꼬리 모양이 따로 있다. 말하는 쪽에 맞는 모양을 고른다 |
| 효과 넣기 | `만화` 도구의 효과 그림(집중선·반짝·땀방울 등)이나 효과 글씨(쾅!·두근두근 등)를 누른다 |
| 다음 칸 만들기 | 아래 칸 목록 끝의 `+`를 누른다. 맨 뒤에 빈 칸이 생긴다. 같은 그림으로 시작하려면 칸 위의 `⋯` 메뉴에서 복제를 고른다 |
| 한 쪽의 칸 수 바꾸기 | `만화` 도구의 칸 배치에서 3칸·4칸·8칸을 고른다. 아래에 전체 칸 수와 쪽 수가 보이고, 칸 목록에는 쪽이 시작되는 칸에 `1쪽`·`2쪽`이 붙는다 |
| 종이에 모인 모습 보기 | 위쪽 `만화 보기`를 누른다. `이전`·`다음`이나 방향키로 쪽을 넘긴다. 칸을 누르면 그 칸을 고치러 간다. `닫기`·Esc로 나온다 |
| 인쇄용으로 내려받기 | 위쪽 `공유` → `다운로드`에서 `만화책 (PDF)`를 고르고 `내려받기`를 누른다. A4 종이 크기이고 첫 쪽 위에 작품 이름이 들어간다 |
| 그림 한 장으로 내려받기 | 같은 창에서 `그림 (PNG)`를 고른다. 지금 보고 있는 칸이 들어 있는 쪽 하나가 나온다 |
| 다른 컴퓨터로 옮기기 | `파일` → `원본 저장`으로 `.canvacomic` 파일을 내려받는다 |

칸은 100개까지 만들 수 있고 모두 같은 가로 긴 모양이다. 만화 작품은 다른 작품과 따로 보관되며 파일도 서로 다르다. 만화 원본(`.canvacomic`)은 만화에서만 열린다.

## 공용 컴퓨터에서 쓸 때

1. 다 만들면 `원본 저장`으로 파일을 내려받아 자기 저장 장치에 옮긴다.
2. 작품 목록에서 휴지통 단추를 눌러 작품을 지운다.

## 문제가 생겼을 때

| 보이는 안내 | 할 일 |
|---|---|
| `읽기 전용` | 같은 작품이 다른 탭에 열려 있다. 그 탭에서 고치거나, 그 탭을 닫고 새로고침한다 |
| `저장 실패` | `원본 저장`으로 내려받는다. 저장 공간이 부족하면 안 쓰는 작품을 지운다 |
| `글꼴을 불러오지 못했어요` | 인터넷 연결을 확인하고 새로고침한다 |
| `문제가 생겼어요` | `새로고침`을 누른다. 마지막으로 저장된 작품은 그대로 있다 |
| 사진이 안 들어가요 | PNG·JPEG·WebP만 넣을 수 있다. 움직이는 그림과 iPhone 사진 형식(HEIC)은 넣을 수 없다 |
| `이 영상은 이 컴퓨터에서 읽을 수 없어요` | 아이폰 기본 형식(HEVC)은 컴퓨터에 따라 안 열린다. 아이폰 설정 → 카메라 → 포맷에서 `높은 호환성`을 고르고 다시 찍는다 |
| `영상이 너무 길어요`, `작품이 너무 길어져요` | 길이 한도(기본 10분)를 넘었다. 보호자가 영상 작품 목록의 `길이 한도`에서 늘리거나, 잘라서 넣는다 |
| `영상 파일이 너무 커요` | 파일 크기 한도(10분마다 2GB)를 넘었다. 길이 한도를 늘리면 함께 늘어난다 |
| `이 컴퓨터에 영상을 넣을 자리가 부족해요`, `영상 파일을 만들 자리가 부족해요` | 디스크 공간이 모자라다. 안 쓰는 영상 작품을 목록에서 지운다 |
| `이 컴퓨터에서는 영상 파일을 만들 수 없어요` | Chrome이나 Edge를 최신 판으로 바꾼다 |
| `배경음악을 불러오지 못했어요` | 애니메이션 도구에서 음악을 다시 고르거나 `음악 없음`을 고른 뒤 내려받는다 |
| `애니메이션 작품 파일이 아니에요`, `만화 작품 파일이 아니에요`, `슬라이드 작품 파일이 아니에요` | 파일 종류가 다르다. `.canvaanim`은 애니메이션에서, `.canvacomic`은 만화에서, `.canvacraft`는 슬라이드에서 연다 |
| `만화 그림을 불러오지 못했어요` | 새로고침한다. 그리기와 글씨는 그대로 쓸 수 있다 |
| 말풍선을 옮기려는데 `요소가 슬라이드 밖으로 완전히 나갈 수 없어요` | 말풍선이나 그 글씨가 칸 밖으로 다 나가는 자리에는 놓을 수 없다. 칸 안쪽에 놓는다 |
| `영상이 커서 원본 파일로 저장할 수 없어요` | 넣은 영상이 1GB를 넘으면 원본 저장이 안 된다. 작품은 이 컴퓨터에 저장돼 있다 |
